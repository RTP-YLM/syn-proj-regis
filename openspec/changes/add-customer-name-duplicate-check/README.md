# add-customer-name-duplicate-check

Implements a feature to check for duplicate customer names before saving. This includes adding a 'Check' button and validation indicator to the customer detail form, a new C# controller action (CustomerController.CheckDuplicateCustomerName) to call the backend API, modifications to Views/Customer/Detail.cshtml for UI integration, and updates to wwwroot/js/page/customer/detail.js for client-side validation and API interaction.
